# Recommendation System

## Description
A movie recommendation system built using Python and Scikit-learn. It recommends similar movies based on genre similarity.

## Features
- Accepts a movie name
- Recommends similar movies
- Uses TF-IDF and Cosine Similarity

## Technologies Used
- Python
- Pandas
- Scikit-learn

## How to Run
1. Install libraries:
   pip install pandas scikit-learn

2. Run:
   python recommendation_system.py
