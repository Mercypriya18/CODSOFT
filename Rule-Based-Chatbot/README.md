# Rule-Based Chatbot

## Description
A simple rule-based chatbot developed using Python. The chatbot responds to predefined user inputs such as greetings, help requests, and basic questions.

## Features
- Greets users
- Answers predefined questions
- Exits when user types "bye"

## Technologies Used
- Python

## How to Run
1. Open Command Prompt.
2. Navigate to the project folder.
3. Run:
   python chatbot.py
